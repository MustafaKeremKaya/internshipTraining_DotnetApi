# internship_training_dotnet_api

Bu proje, staj sürecimde eğitim amacıyla geliştirilmiş kapsamlı bir backend / web API uygulamasıdır. Projenin temel amacı, endüstri standartlarında servisler geliştirmek ve veritabanı entegrasyon süreçlerini uygulamalı olarak pekiştirmektir.

## 📚 Proje Hakkında

Bu repo, [ilgili YouTube eğitim serisindeki](https://youtube.com/playlist?list=PLqG356ExoxZVN7rC0KmMo0lvECK97VRZg&si=iFwLByIRKyezyrFR) müfredat ve yönergeler takip edilerek adım adım inşa edilmiştir. Geliştirme süreci boyunca mimari yaklaşımlar, temiz kod prensipleri ve modern framework kullanımları üzerine odaklanılmıştır.

## 🛠️ Kullanılan Teknolojiler

Proje geliştirme sürecinde aşağıdaki teknolojiler ve araçlar kullanılmıştır:

* **Dil:** C#
* **Framework:** .NET Web API / ASP.NET Core
* **Veritabanı:** PostgreSQL
* **Geliştirme Ortamı:** Visual Studio / VS Code
